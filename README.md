## 运行

1. 使用 Godot 4.7/4.7.x 项目管理器导入 `project.godot`。
2. 按 `F5` 运行。

普通运行不依赖外部插件、字体、模型或音频包。系统没有可用中文 TTS 时，语音会自动跳过。

重新生成旧版程序化占位美术需要 Python 3 和 Pillow：

```bash
python tools/generate_visual_assets.py
```

重新处理本版 AI 源图、去除灰底并生成对齐图集：

```bash
python tools/process_ai_assets.py
```

## 当前边界
