# 架构说明 v0.8.4

## 1. 模拟层与表现层

地图仍使用矩形整数瓦片：寻路、占地、矿石、树林、战争迷雾和建筑 footprint 以格子为准；单位和建筑使用程序化三分之四视角序列帧、Y 排序和地面阴影形成 2.5D 表现。

## 2. 群体移动与碰撞

单位使用 `CharacterBody2D + CollisionShape2D`。移动链路为：

```text
AStarGrid2D 全局路径
→ 动态编队目标
→ 邻居径向分离
→ 稳定方向的切向绕行
→ move_and_slide 物理碰撞
→ 多轮穿透修正
→ 卡住后的侧向恢复与重新寻路
```

v0.8.0 的关键修正：

- 编队间距取决于最大单位碰撞半径；
- 目标阵型以点击点居中；
- 移动、攻击移动、巡逻统一使用阵型目标；
- 到达 A* 终点不再硬吸附坐标；
- 空闲单位也持续执行穿透修正。

这能处理常见的小规模堆叠，但仍不等价于 ORCA/RVO。

## 3. 双类别建筑产能

建筑施工状态按类别分离：

```text
structure_jobs.primary / ready_structures.primary
structure_jobs.defense / ready_structures.defense
```

两个类别每帧独立推进，因此主要建筑和防御建筑可以同时建造。每类仍只有一个施工位和一个就绪位。

## 4. 维修系统

### 建筑维修

建造栏顶部扳手进入目标模式。点击受损己方建筑后，将建筑加入 `repairing_buildings`，每帧调用统一维修事务。

### 车辆维修

车辆右键装甲维修厂后执行：

```text
驶向入口
→ 原单位节点进入维修厂并隐藏
→ 关闭碰撞但保留生命、经验、等级和实例身份
→ 按秒恢复并扣费
→ 满血后搜索空闲出口
→ 恢复同一节点并驶出
```

维修费用：

```text
每点生命费用 = 原价 × 0.40 / 最大生命
```

使用小数余额缓冲，避免逐帧向上取整导致总价超过 40%。

## 5. 建筑变卖和施工动画

建筑部署后 `construction_progress` 从 0 增至 1，表现为从地面展开。变卖时同一进度反向播放至 0，然后移除占地、返还资金并释放节点。

返还比例：

```text
25% + 当前生命比例 × 50%
```

因此完全损毁边缘为约 25%，满血为 75%。

## 6. 防御塔表现

建筑图集不再直接用 `hframes` 共享采样，而是由 `sprite_sheet_factory.gd` 为每个受损阶段创建独立 `AtlasTexture` 并开启 `filter_clip`，防止相邻帧阴影串入当前建筑。

防御塔攻击时同时更新：

- 炮管方向；
- 精灵后坐位移；
- 轻微旋转与缩放；
- 炮口闪光；
- 弹道和伤害。

敌我防御塔共用同一路径。

## 7. 战术 AI

每个可移动单位保存：

- `retaliate_enabled`：闲置、停止或原地防守时受击是否反击；
- `support_enabled`：附近友军受击时是否接受支援命令。

`G` 键在四种组合间循环。支援只覆盖当前无强制任务的作战单位，避免玩家下达的移动、巡逻和攻击命令被轻易覆盖。AI 出生单位显式默认开启反击与支援。

## 8. 强制攻击和环境目标

`Ctrl+A` 进入强制攻击模式。命令可以保存实体目标或纯地面坐标：

- 实体存在时持续追踪其位置；
- 到达射程后播放攻击动画并结算直接/范围伤害；
- 矿石实现无敌 `take_damage()`，因此可被瞄准但不会损耗；
- 树木可受伤并在归零后移除车辆阻挡。

## 9. 树林与双寻路网格

`grid_world.gd` 维护两套 A*：

- `astar_infantry`：允许进入茂密和稀疏树林；
- `astar_vehicle`：茂密树林为阻挡，稀疏树林可通行。

树林格内单位的伤害乘数为 `0.75`。建筑部署检测同时拒绝树木占用格。

## 10. 公平陆战地图

所有遭遇战地图尺寸位于 50～100 格，`style=balanced_land`，不会生成水域。地图数据显式保存出生点和矿区中心：每位玩家拥有近似等距的一矿、二矿，公共矿区采用镜像或旋转对称布局。树木布局也通过象限镜像生成。

## 11. UI

战役菜单使用 `MarginContainer + VBoxContainer + HBoxContainer`，不再使用会在缩放时重叠的绝对定位。建造栏顶部工具按钮使用独立 `SidebarToolButton`，不会挤压四列生产方格的逻辑。

## v0.8.0 分层精灵渲染

- `tank_chassis.png`：8方向底盘，包含静止与两帧移动。
- `tank_turret.png`：8方向独立炮塔，包含瞄准与开火。
- `unit.gd` 分别维护 `visual_direction` 与 `turret_visual_direction`，因此底盘移动方向和炮塔瞄准方向互不绑定。
- `turret_base.png` / `turret_head.png`：防御炮塔固定基座与独立旋转炮头。
- `bunker_base.png` / `bunker_head.png`：机枪碉堡固定基座与独立旋转机枪模块。
- AI 源图保存在 `assets/ai_generated/source_sheets/`，运行时图集由 `tools/process_ai_assets.py` 生成。

## v0.8.4 视觉配置层

单位与建筑根节点继续保持逻辑尺寸不变。`VisualProfileStore` 根据实体 ID 加载 `resources/visual_profiles/<id>.tres`，只将缩放和偏移应用到视觉子节点。独立炮塔使用额外的炮塔倍率和偏移，因此可以在 Inspector 中校准挂点，而不会改变寻路、碰撞或占地。

## v0.8.4 矿区地形语义

矿石是可选中资源实体，但不是物理碰撞体或导航阻挡。其所在格只提供 0.86 的地面速度倍率，并通过 `can_place()` 阻止建筑部署。采矿车直接进入矿格采集，自动分配逻辑尽量避免两辆车争抢同一矿格。
