# v0.16.0-dev.6 高度地图与载具 2.5D 姿态基础

日期：2026-07-28  
基础版本：v0.16.0-dev.5 Runtime Hotfix

## 本轮定位

本轮没有宣称完成真正的 RA2 等距地图或 VXL 体素运行时渲染，而是先把此前只有数据字段的 `height_levels`、`slope_types` 接入实际游戏表现，建立后续等距地图、悬崖寻路和 VXL 物理的运行时接口。

## 已实现

### 1. 连续地面高度采样

`GridWorld` 新增：

- 八方向坡面类型。
- 每级 16 px 的高度步长。
- `get_ground_sample(world_position)`。
- `get_ground_height(world_position)`。
- `get_ground_gradient(world_position)`。

坡面单元不再只返回一个离散层级，而是根据单位在格子内部的位置计算连续高度，使单位进入和离开坡面时不会瞬间跳变。

### 2. 自动坡道

地图的 `height_zones` 现在可设置：

```json
{
  "center": [32, 32],
  "radius": 10,
  "level": 1,
  "auto_ramps": true,
  "ramps": ["north", "east", "south", "west"],
  "ramp_width": 1
}
```

生成器会在高地边缘建立指定方向的坡面单元，并清除坡道上的树木。

### 3. 地形轮廓显示

当前矩形地图增加临时高度可视化：

- 高地区域轻微着色。
- 高度边缘绘制暗色轮廓。
- 坡面绘制方向标记。

这只是开发阶段的高度调试表现，不是最终 RA2 等距 TMP 悬崖素材。

### 4. 载具坡面姿态

RA2 平面视觉和分层载具视觉均新增 `set_terrain_pose()`：

- 根据地面高度上移视觉。
- 根据坡面梯度调整车体旋转和倾斜。
- 炮塔和车体分层结构保持在同一姿态根节点中。
- 分层载具阴影在载具腾空时留在地面。

步兵仅跟随高度，不应用明显车体倾斜。

### 5. 建筑高地适配

- 建筑视觉会按照所在高度层上移。
- 建造位置必须满足整个 Foundation 位于同一高度层。
- 坡面上禁止放置建筑。
- 建筑血条和 RA2 视觉顶部计算会跟随高度偏移。

### 6. 炮弹高度

抛射体现在记录起点和终点地面高度：

- 炮弹轨迹在地面高度插值之上计算抛物线。
- 高地向低地、低地向高地射击时，炮弹不再沿固定屏幕平面飞行。
- 爆炸视觉在目标地面高度处生成。

### 7. 冲击掀起基础

RA2 载具新增：

- 平面冲击速度。
- 垂直速度。
- 腾空高度。
- 翻滚角速度。
- 重力和落地过程。
- 高速落地伤害。

带范围伤害的攻击命中机械单位时，可根据实际伤害施加有限的击退、抬升和翻滚。该实现是 2.5D 物理基础，不是完整刚体模拟。

### 8. 高地试验场

新增地图：`highland_trial / 高地试验场`。

用途：

- 验证四向坡道。
- 验证载具倾斜。
- 验证高低地炮弹轨迹。
- 验证范围攻击掀起。
- 验证坡面和跨层 Foundation 禁止建造。

测试地图独立存放于 `data/maps_height.json`，由 `GameConfig` 合并进入地图列表，不修改现有正式遭遇战地图的平衡。

## 明确未完成

1. 地图底层仍是 32×32 矩形逻辑网格，不是 RA2 菱形等距坐标。
2. 高地轮廓是程序化调试绘制，不是原版悬崖、坡面和海岸 TMP。
3. 尚未实现悬崖边缘的逐边寻路限制。当前坡面会影响速度和建造，高度边缘仍可能被单位从非坡道方向跨越。
4. 尚未把高度纳入射程、视线遮挡和弹道碰撞判定。
5. 尚未解析 `IsoMapPack5`。
6. 尚未把 VXL 转换为 Godot 3D 网格或体素数据；当前仍使用预烘焙方向帧。
7. 树木和矿石实体的视觉高度适配尚未完成。

## 本机验证重点

1. 进入“高地试验场”，确认中央高地、四向坡道和高度轮廓可见。
2. 坦克从四个坡道进入高地，确认车体逐渐倾斜且不瞬移。
3. 步兵进入高地时只改变视觉高度，不发生明显旋转。
4. 在坡面以及跨越高低层的位置放置建筑，应显示不可建造。
5. 高地坦克向低地目标开火，炮弹轨迹应跟随起止高度。
6. 使用带范围伤害的武器攻击载具，确认载具存在击退、腾空、翻滚和落地过程。
7. 腾空载具的阴影应留在地面附近，而不是贴着载具一起上升。
8. 检查空闲、移动和交火 FPS，确认本轮每单位姿态更新没有重新引入明显性能回退。
9. 检查 Godot 调试器是否有 Parser Error、Invalid call 或持续刷屏警告。
