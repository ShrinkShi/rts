# v0.9.1 可视化预制场景重构

- 为全部 5 种单位和 8 种建筑建立真实 `.tscn` 预制场景。
- 单位和建筑现在通过 `PackedScene.instantiate()` 生成，而不是只通过脚本 `.new()` 动态拼装视觉节点。
- 精灵、炮塔、碰撞体、烟雾挂点、矿石载荷条挂点均可在 Godot 2D 编辑器直接拖动。
- 动画拆分为外部 `SpriteFrames` `.tres`，打开场景即可看到实际精灵，不依赖 `@tool` 预览脚本。
- 修复旧预览器在编辑器热重载时出现 `Nil.has` 和 `stand_0` 不存在的问题。
- `ServiceAnchor` 现在会实际控制生产出口和维修入口位置。
- 保留旧 `visual_profiles` 作为动态回退兼容层，不再作为主编辑入口。
