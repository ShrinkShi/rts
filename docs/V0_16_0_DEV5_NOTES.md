# v0.16.0-dev.5 RA2 规则、音频与阵营防御更新

日期：2026-07-28  
基础版本：v0.16.0-dev.4

## 数据来源与适用范围

本轮数值以仓库中由 `rules.ini`、`rulesmd.ini`、`art.ini`、`artmd.ini` 提取出的对象数据为依据：

- `data/ra2/entities/*.json`
- `data/ra2/warheads.json`
- `data/ra2/runtime_profiles.json`

运行时对齐字段包括：`Cost`、`Strength`、`Armor`、`Speed`、`Sight`、主武器 `Damage`、`ROF`、`Range`、`Warhead`、建筑 `Power` 和美术 `Foundation`。

这不是完整复刻原引擎的全部规则键。当前仍使用本项目的矩形网格、秒制更新和简化弹道，因此：

- `ROF` 暂按 30 tick/s 转为秒。
- 原版 Speed 暂按项目移动尺度换算。
- 原版十一种 Armor 索引仍用于读取 `Verses`，但目标单位在项目层归并为生物、机械、建筑三类。
- 数字护甲值是本项目新增的第二层减伤，不等同于原版 Armor 枚举。

## 已实现

### 战斗音频

- 武器开火、单位受击、单位死亡、建筑受击和建筑摧毁改用战场空间音频。
- 只有声音源位于当前可见战场矩形内时才播放。
- 视野中心按 100% 相对音量播放，向边缘线性衰减到约 34%。
- 使用 `AudioStreamPlayer2D` 提供左右声道定位，距离曲线由可见战场矩形统一计算，避免相机缩放造成二次衰减。
- 副官播报继续使用非空间音频，不受视野裁剪。

### 电脑维修建筑

- 电脑定期扫描自己的受损建筑。
- 优先维修生命比例最低的建筑。
- 使用现有建筑维修费用和资金校验。
- 维修时开启扳手图标；修满或资金不足后关闭。

### 弹头、护甲类型和护甲值

- 新增 `RA2RulesAdapter`，读取原版武器和弹头数据。
- 目标护甲归并为：
  - 生物护甲：步兵。
  - 机械护甲：车辆和飞行器。
  - 建筑护甲：建筑。
- 保留原版 Warhead `Verses` 百分比作为第一层伤害倍率。
- 增加独立数字护甲值作为第二层减伤。
- 原有基础脚本的固定数值减甲被关闭，避免重复扣减。
- `AP` 弹头由验证器检查：`25%,25%,15%,75%,100%,100%,65%,45%,60%,60%,100%`。

### 防御建筑调整

- 盟军两个防御槽改为：
  - 爱国者飞弹兼容实现。
  - 机枪碉堡 `GAPILL`，价格保留为 650。
- 苏联两个防御槽改为：
  - 防空炮 `NAFLAK`，只攻击空中目标。
  - 哨戒炮 `NALASR`，攻击地面目标；运行时地面锚点和后备炮塔节点均上移。
- 尤里两个防御槽改为：
  - 盖特机炮 `YAGGUN`，可攻击地面和空中目标。
  - 坦克碉堡 `NATBNK`，没有自身武器。

### 坦克碉堡

- 坦克右键点击己方空坦克碉堡会驶向入口并进驻。
- 每座坦克碉堡暂时容纳一辆坦克。
- 进驻坦克从地图单位列表、碰撞和选择中移除，免受外部直接伤害。
- 碉堡被出售或摧毁时，坦克会从附近可用位置撤出。
- 当前没有实现“坦克在碉堡内部继续以自身武器开火”，本轮只实现保护和进出逻辑。

### 树木

- 茂密树林对车辆的树干碰撞半径进一步缩小到单格宽度的 14%。
- 步兵继续忽略树木碰撞并获得现有 25% 掩体减伤。
- 树木节点增加原版 RA2 树木 PNG 查找器和最近邻显示。
- 当前仓库未确认存在已转换的原版树木 PNG；找不到资源时仍使用程序化树木，不伪装成已经完成素材替换。

### 寻路、残骸与命令

- 占用终点的收尾逻辑覆盖普通移动和攻击移动。
- 停止状态的坦克保留最后稳定车体朝向，阻止原地连续切换八方向。
- 步兵残骸时间缩短到约 3.2 秒，车辆和建筑残骸约 3.8 秒。
- 已核对地图目标输入链路：移动、攻击移动、巡逻、采集、集结点、维修、出售、强制攻击和防御建筑攻击均经地图左键目标路由。

### Foundation 与原版数值

- 建筑创建后读取对应 RA2/YR 对象的 `Foundation`，更新占格、碰撞、中心点和视觉布局。
- 玩家建造栏在开始建筑任务前同步写入对应 Foundation，减少放置预览和最终占格不一致。
- 玩家建造栏显示并支付运行时 RA2 对象价格。
- 单位和建筑生成后使用对应阵营 RA2 对象的生命、视野、移动、武器和电力数据。

## 明确边界

1. 仓库没有 `GAPATS` 的提取对象和预览资源。盟军爱国者当前使用可用的 `NASAM` 导弹阵地数据/视觉作为兼容实现，并覆盖中文名称。它不是精确的 `GAPATS` 复原。
2. 仓库未确认存在已转换的原版树木 PNG。代码已接入资源查找，但资源缺失时仍回退程序化树木。
3. 电脑单位和建筑生成后的战斗数值会对齐对应 RA2 对象；电脑生产付款仍经过旧的通用生产入口，尚未完成按不同阵营对象价格分别结算的核心重构。
4. 坦克碉堡目前只提供进驻和保护，不会让内部坦克向外射击。
5. 本提交尚未在 Godot 4.7.1 中完成 Parser 和 F5 对局验证。
