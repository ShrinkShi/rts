Limitations
-----------
- No Godot 4.7.1 executable is installed in this build container, so this
  report does not claim an editor F5 or headless engine parse/run test.
- VXL movement usually has no frame animation in the source format; runtime
  movement currently changes direction while using the rendered Stand frame.
- VXL vehicle death currently uses the existing explosion/fade fallback.
- Independent runtime turret rotation is not yet separated from the baked
  VXL composite preview for every vehicle.
- Current gameplay remains the existing Iron Meridian ruleset with RA2/YR
  visuals/audio mapped onto its playable slots. Full RulesMD mechanics are
  not claimed in this release.
