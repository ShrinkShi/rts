# v0.8.1 发布说明

本版本集中修复 AI 生成序列帧的方向和锚点错误。

## 修复

1. 步枪兵源图实际方向顺序为南、南西、西、北西、北、北东、东、南东，现已正确映射到引擎的东、南东、南、南西、西、北西、北、北东。
2. 步兵与坦克移动帧不再继承源图每一行的排版偏移，而是围绕稳定脚底或炮塔环锚点重新排版。
3. 坦克底盘和炮塔都以炮塔环为共同枢轴，炮塔节点不再额外上移。
4. 防御炮塔与机枪碉堡的枪头以安装座中心为枢轴，解决枪头脱离基座。
5. 建筑帧以地面占地中心作为锚点，选择框、碰撞体、瓦片占地和图像基座重新对齐。
6. 图集后处理会删除相邻格泄漏的碎片，只在开火帧保留暖色炮口焰。
