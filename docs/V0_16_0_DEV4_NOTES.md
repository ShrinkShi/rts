# v0.16.0-dev.4 玩法规则与基地车更新

日期：2026-07-28  
基础版本：v0.16.0-dev.3

## 已实现

- 单位接近已被其他单位占据的移动终点时就地完成命令，避免围绕集结点持续左右摇摆。
- 缩小茂密树林对车辆的物理阻挡半径；步兵继续将树林视为可进入掩体，并强制移除树木碰撞层。
- 单位生产队列上限提高到每座生产建筑 30 个；Shift + 鼠标左键一次尝试加入 5 个。
- 降低分层坦克基础层和所属色层亮度，减少发白现象。
- 部署状态单位不会再响应普通右键移动；混合选择时 D 优先部署未部署单位，全部已部署时才统一解除部署。
- 采矿车基础生命值从 650 提高到 3250。
- 新增三方基地车映射：AMCV、SMCV、PCV。建造中心按 D 收起为基地车并继承生命值，基地车按 D 在合法 3×3 区域展开。
- 胜负改为建筑体系判定：建造中心单独被摧毁不会直接失败；玩家失去全部建筑且没有已收起的基地车时才被击败。
- 玩家被击败时在左上角显示“XXX被击败了”。
- 不满足前置建筑的单位和建筑不显示在生产侧栏，前置恢复后自动出现。
- 建筑生命条上移，避免被高建筑主体遮挡。
- 战车工厂生产时保留完整 Operational 组合图，不再切到缺少 Bib/坡道的组件动画。
- 采矿车卸矿时保留在精炼厂服务格，车头朝外、车尾对准精炼厂；运行时优先尝试 CMINWO/HARVWO 等卸矿视觉，预览资源缺失时回退普通模型。
- 电力显示改为“当前耗电量 / 总发电量”。

## 设计边界

- 当前仓库没有 `CMINWO`、`HARVWO` 的已生成运行时预览包，因此卸矿模型切换逻辑已接入，但缺失资源的阵营会回退普通矿车模型。
- 基地车收起/展开目前是即时状态转换，尚未加入原版建造厂收放动画和音效序列。
- 本提交仍需在 Godot 4.7.1 中进行 Parser 与 F5 对局验证。
