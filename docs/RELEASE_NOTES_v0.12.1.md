# v0.12.1 — RA2/YR 双音频银行完整接入

## 修复目标

补齐 v0.12.0 缺失的尤里复仇音频银行，不再把 RA2 与 YR 的 `audio.idx/audio.bag` 混成单一来源。

## 完成内容

- 新增 `--audio-md` / `--audio-md-root` 管线参数。
- Windows 构建脚本默认同时读取 `audio.zip` 与 `audiomd.zip`。
- 物理输出按来源分离：
  - `assets/ra2_audio/ra2/...`
  - `assets/ra2_audio/ra2md/...`
- 同名样本按 `RA2 < YR` 优先级解析，同时保留低优先级来源和覆盖记录。
- 资源数据库试听列表显示样本所属音频银行。
- 音频清单升级为 schema 2，记录银行统计、唯一样本和覆盖关系。

## 回归约束

验证脚本现在强制要求：

- 音频银行数量为 2。
- 优先级必须为 `ra2 → ra2md`。
- 1,825 个 Sound 样本引用全部解析。
- 所有解析后的 `res://` 音频路径存在。
- 所有从 BAG 生成的 WAV 具有正确 RIFF 长度。

当前环境无 Godot 4.7.1 可执行文件，仍需用户本机完成首次资源导入及 F5 回归。
