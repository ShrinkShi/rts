# v0.10.0：RA2/YR 全量兼容沙盒

## 已接入内容

- 直接读取用户提供的 `ra2.zip`、`ra2md.zip`，解析 `rules.ini/rulesmd.ini`、`art.ini/artmd.ini`。
- 建立 14 个国家定义、5 个 Side、10 个多人可选国家、65 个步兵定义、80 个载具定义、12 个飞行器定义、403 个建筑/地图对象、12 个超级武器、167 个被引用武器和 76 个被引用弹头的结构化数据库。
- 将 127 个可生产或开局对象转换为运行时资源：74 个单位、53 个建筑。
- 为全部 127 个对象生成 SHP 或 VXL/HVA 视觉资源，不依赖运行时读取原始 Westwood 二进制文件。
- 遭遇战国家列表加入美国、韩国、法国、德国、英国、苏俄、利比亚、古巴、伊拉克和尤里。
- 生产栏改为按国家、阵营、科技等级、前置建筑和国家限制动态生成。
- 接入 `SecretHouses`、三类 `RequiresStolen*Tech` 和 `BuildLimit`；渗透科技已建立解锁接口，但间谍渗透行为本身仍待实现。
- 三个主要阵营拥有各自的开局建造厂、电厂、矿场、兵营、战车工厂、基础步兵、基础坦克、矿车和基地车。
- 除通用兜底场景外，为 74 个单位和 53 个建筑逐一生成真实 `.tscn` 预制场景。运行时会按实体 ID 加载对应场景，可在 Godot 2D 编辑器直接调整精灵、炮塔、碰撞体和挂点。
- 武器层接入基础伤害、射程、ROF、护甲类型，以及 Warhead 的 `Verses`、`CellSpread`、`PercentAtMax`。
- 抽象前置建筑 `POWER/PROC/BARRACKS/NAPILE/RADAR/TECH` 可正确映射到当前国家实际建筑，不再造成科技树永久锁死。
- AI 可从当前国家生产列表中选择已有生产建筑能够制造的地面作战单位，并按防御、生产、维修、经济和建造中心评估目标价值。
- 将资源包内可直接获得的 23 个 AUD 文件转为 OGG；同时保留 SHP、VXL/HVA、WAV、AUD 的离线导入工具。
- 新增 RA2/YR 数据库浏览器和 `tools/validate_ra2_runtime.py` 全量运行时完整性检查。

## 当前实现性质

本版本把全部可生产/开局素材和主要 Rules 数据接入了一个可以进行经济、生产、移动和通用交战的 Godot 沙盒。它解决的是“先用现成素材验证 RTS 引擎逻辑”的问题。

它仍不是原版行为的逐项完整复刻。空军、海军、驻军、工程师、间谍、心灵控制、部署、运输、IFV 乘员武器、超级武器、原版脚本 AI、地图格式和完整音频银行等，需要继续在 Godot 中实现专门状态机。具体清单见 `docs/RA2_FULL_REPLICATION_SCOPE.md`。
