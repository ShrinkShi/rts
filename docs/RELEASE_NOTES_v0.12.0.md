# v0.12.0 — CSF、本地音频银行与官方地图接入

## 目标

这一版只解决用户新提供资源所对应的基础层，不把“读取到文件”包装成“玩法已经完成”。重点是让 Godot 工程能够稳定消费官方文本、声音和扩展包覆盖，并能在资源数据库中核验结果。

## 已完成

### CSF 本地化

- 新增严格 CSF 解析器，校验 `FSC` 文件头、标签和值数量。
- 支持 RA2 使用的反码 UTF-16LE 文本和带额外字符串的 `WRTS` 记录。
- 按 `ra2.csf → ra2md.csf` 合并，保留覆盖历史。
- 生成 `localization.json` 和适合 Godot 列表浏览的 `localization_catalog.json`。
- Rules 中的 `UIName` 已解析为显示名称，同时保留原始 CSF 标签。

### IDX/BAG 与 WAV

- 解析 `audio.idx` 的 `GABA` 索引和 36 字节记录。
- 支持 PCM 16 位单声道/立体声以及 IMA ADPCM 单声道/立体声。
- BAG 数据被封装为标准 RIFF/WAV，不进行有损转码。
- 1,153 个 BAG 样本和 459 个独立 WAV 被放入 Godot 资源目录。
- Sound 事件保留 `Control`、`Volume` 等原始字段，并关联实际可播放样本。
- 资源数据库支持逐事件试听与缺失引用显示。

### 官方扩展包

- `expandmd01`、`expandmd03`、`expandmd04` 作为高优先级资源层参与索引。
- 相同文件名优先使用后加载扩展包，并保留 pack 来源。
- `expandmd01/rulesmd.ini` 与 `soundmd.ini` 会覆盖基础 YR 配置，字段来源和历史不会丢失。
- 13 张地图复制到 `assets/ra2_maps`，并解析剧院、地图尺寸、可见区域、路径点和脚本结构数量。

### Godot 数据库界面

资源数据库新增四种浏览模式：

1. 单位与建筑
2. 声音事件
3. CSF 本地化
4. 官方地图

单位详情会同时显示中文名称、素材关系、武器链、声音角色和字段来源。

## 数据结果

- 源资源：11,593
- 对象：559
- CSF 文本：5,212
- 已本地化对象：497
- BAG 样本：1,153
- 独立 WAV：459
- 声音事件：526
- 已解析声音引用：928 / 1,825（50.8493%）
- 官方地图：13

声音引用没有达到 100%，不是解析器默默吞掉错误，而是当前提供的音频银行没有覆盖所有 `sound.ini/soundmd.ini` 样本名。缺失名称会保留在 `missing_samples` 中。

## 验证

已完成：

- 全部 Python 管线文件编译检查。
- 全部 JSON 解析检查。
- 41 个 GDScript 文件的静态结构检查。

- PCM mono/stereo、IMA ADPCM mono/stereo 四类代表样本的 FFprobe 解码检查。

- 扩展包字段来源检查。

当前构建环境没有 Godot 4.7.1 可执行文件，因此仍需在用户本机执行一次编辑器导入和 F5 回归测试。
