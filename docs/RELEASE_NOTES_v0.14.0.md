# Iron Meridian RTS v0.14.0

## 目标

v0.14.0 不再只停留在 RA2/YR 资源浏览器。三套基础阵营纵切已把真实 SHP、VXL/HVA、所属色遮罩和音频事件接入遭遇战运行时。

## 浏览器修复

- CSF 名称会在运行时解析，`Name:CAR`、`Name:PIGCAR` 等原始标签不再直接显示。
- 海豚与巨型乌贼使用独立的顺时针 SHP 方向映射，修复东西方向颠倒。
- 盖特坦克拆分为 `Stand` 与 `Fire`：普通状态保留炮塔但不播放开火 HVA，攻击状态播放完整 HVA。

## 遭遇战运行时接入

现有三个内部阵营 ID 保留以兼容存档和游戏逻辑，但显示为：

- `union` → 盟军
- `dominion` → 苏军
- `republic` → 尤里

### 单位映射

- 盟军：美国大兵、重装大兵、灰熊坦克、多功能步兵车、超时空采矿车。
- 苏军：动员兵、防空步兵、犀牛坦克、防空履带车、武装采矿车。
- 尤里：尤里新兵、病毒狙击手、狂风坦克、盖特坦克、奴隶矿场载具。

### 建筑映射

三方的建造厂、发电设施、兵营、精炼厂、战车工厂、维修/回收设施和基础防御建筑均改用对应 RA2/YR 建筑预览资源。

## 状态映射

- 步兵：待机、移动、开火、死亡使用真实 Sequence。
- VXL 载具：八方向车体/炮塔/炮管组合；盖特坦克额外区分普通与开火 HVA。
- 建筑：建造进度、正常工作、受损、摧毁残骸、生产、维修和精炼厂卸矿特殊动画。
- 所属色：基础图层与 remap 遮罩双层渲染。
- 音频：选择、移动命令、攻击命令、武器 Report、死亡事件进入实际游戏。

## UI

- 生产栏和选中实体头像优先使用 RA2/YR 运行时图像。
- 生产栏和选中实体名称按当前阵营映射到 CSF 名称。

## 明确边界

- 当前仍沿用 Iron Meridian 的通用数值和生产逻辑，不是完整 RulesMD 行为复刻。
- VXL 通常没有内嵌移动/死亡序列：移动使用方向切换，死亡暂用现有爆炸效果与淡出。
- 机场、海军、驻军、心灵控制、部署形态、超级武器等仍是后续机制阶段。
- 生产图标目前来自运行时首帧，不是完整 Cameo 管线。
