# v0.8.4 发布说明

## 可视化校准资源

新增 `resources/visual_profiles/*.tres`。单位和建筑的图片缩放、偏移、独立炮塔缩放与偏移可以直接在 Godot Inspector 中调整，不再需要修改运行时代码。

## 矿区通行与采矿车状态机

- 矿石实体不具有碰撞体，也不进入 A* 阻挡集合。
- 所有单位可以驶入和穿过矿石格。
- 活跃矿石格使移动速度降低 14%。
- 建筑不能部署在仍有矿石的格子上。
- 自动采矿车直接驶入矿石格采集，不再围绕矿区争抢八个外圈接近点。
- 自动寻矿会惩罚已被其他采矿车占用的矿格。
- 连续三次脱困失败会释放矿格或重新选择精炼厂入口，避免永久停滞。

## 坦克图集扩边

AI 原始联系表中的坦克和炮塔存在跨格内容。素材处理器现在带重叠区域切格，再删除相邻主体残片。坦克底盘、炮塔和死亡图集统一扩大为每帧 224×192，并保留更大的透明安全边缘。

左右炮管从重叠区恢复，长度明显更一致。坦克视觉资源默认缩小到 0.83 倍以保持原来的世界尺寸，独立炮塔默认放大到 1.10 倍。
