# v0.16.0-dev.7 可见高地、坡道与哨戒炮视觉修正

日期：2026-07-29  
基础版本：v0.16.0-dev.6 Parser Hotfix 1

## 用户实机结论

- v0.16.0-dev.6 的 Parser Hotfix、运行稳定性、高度采样、载具坡面姿态、弹道高度和冲击掀起未发现新的阻断性问题。
- `highland_trial / 高地试验场` 虽有高度数据，但原先只有浅色轮廓与方向线，无法形成类似 RA2 坡道和悬崖的视觉辨识度。
- 苏军 `NALASR` 哨戒炮的组合预览出现异常白蓝色团块，主体、炮塔与炮管关系不可辨认。

## 本轮完成

### 1. 矩形高地测试结构

- 高地试验场从圆形高度区域改为 22×16 的矩形一级高地。
- 北、东、南、西各设置五格宽坡道。
- 地图描述与矿区位置同步调整，使坡道和悬崖附近保持可测试空间。

### 2. 可见高地顶面

- 新增 `HeightTerrainOverlay`。
- 一级高地顶面重新绘制到高程位置，不再只在原地面上叠加浅色边框。
- 顶面继续采样现有温带地形图集，避免高地变成纯色调试块。
- 高地边缘加入明暗轮廓，强化台地边界。

### 3. 悬崖立面

- 南侧高度落差绘制岩层立面、分层横纹、裂纹与底部暗线。
- 东侧高度落差绘制窄侧壁和阴影。
- 当前矩形网格仍不是 RA2 菱形等距网格，因此本轮采用与现有坐标体系兼容的伪 2.5D 悬崖表现。

### 4. 方向坡道

- 八方向坡面均支持四角高度变形。
- 高地试验场实际使用四个正方向坡道。
- 坡道增加暗色履带痕迹和浅色坡向标识，使其与垂直悬崖明显区分。
- 原有格内连续高度采样、车辆倾斜和坡面减速继续使用同一 `slope_types` 数据。

### 5. 非坡道悬崖通行限制

- 高地边缘如果与低地相邻且附近没有坡道入口，会在步兵与车辆 AStar 中标记为不可通行。
- 单位只能从预留坡道开口进入高地，不再直接穿越普通悬崖边缘。
- 该实现以格子阻挡近似悬崖边界，尚未升级为边级寻路连接模型。

### 6. 苏军哨戒炮视觉重构

问题来源：

- `NALASR` 的运行时 `Ready` 预览是“主体 + 持久组件 + 炮塔”的合成帧。
- 当前合成结果在实际游戏中出现异常团块，继续缩放和移动整个合成图无法从根本上修复。

本轮处理：

- 不再使用异常的 `Ready` 合成帧作为正常显示。
- 强制使用 RA2 预览包中的 `BodyStates/body_normal` 或 `body_damaged` 作为底座。
- 新增独立程序化炮塔头：
  - 低矮圆形转台。
  - 清晰炮管。
  - 所属色识别点。
  - 八方向连续朝向。
  - 受损变暗。
  - 开火枪口闪光。
- 哨戒炮底座宽度由 44 px 缩小到 36 px，移除之前的负 Y 偏移。

## 明确边界

1. 当前悬崖和坡道是适配 32×32 矩形逻辑网格的伪 RA2 风格绘制，不是原版 `IsoMapPack5`、菱形 TMP 和真实 cliff/ramp tile 拼接。
2. 当前哨戒炮炮塔是修复异常合成帧的程序化替代视觉，不是从原版 VXL/SHP 中精确重建的炮塔资源。
3. 悬崖通行限制目前通过阻挡高地边缘格实现，后续应改为“边连接”寻路，避免占用高地可站立面积。
4. 本提交尚未在 Godot 4.7.1 中通过 Parser、F5 对局与性能验证。

## 实机验证清单

1. 高地试验场中央是否明确出现矩形台地，而不是浅色圆形轮廓。
2. 南侧是否可见岩层悬崖立面，东侧是否可见侧壁阴影。
3. 四向坡道是否能与普通悬崖一眼区分。
4. 坦克和步兵是否只能从坡道进入高地。
5. 坦克在坡道上的倾斜和速度变化是否仍正常。
6. 高地顶面是否与原草地/泥地风格协调，是否出现新的瓦片接缝。
7. 苏军哨戒炮是否不再显示白蓝色异常团块。
8. 哨戒炮底座、炮塔和炮管比例是否合理，转向与开火反馈是否正常。
9. 建筑受损后底座是否切换受损帧，炮塔是否同步变暗。
10. 调试器是否出现 Parser Error、Invalid call 或持续刷屏。
