# v0.8.2 发布说明

## 修复内容

1. 生产栏中的主战坦克图标改为底盘与炮塔合成显示，不再只显示空炮塔环底盘。
2. 防御炮塔和机枪碉堡图标改为固定基座与旋转武器模块合成显示。
3. 防御建筑技能栏加入“强制攻击”，支持 Ctrl+A 后指定地面、树木、矿石、友军或敌方目标。
4. AI方向图集统一采用 `上、左上、左、左下、下、右下、右、右上` 的可读顺序。
5. 引擎运行时显式将数学方向索引 `右、右下、下、左下、左、左上、上、右上` 映射到图集列，避免素材列顺序和逻辑方向耦合。
6. 原始坦克底盘图缺少可靠的右侧角度，使用对应左侧角度水平镜像生成右下、右、右上，去除错误重复帧。
7. 步兵图集按原始方向重新排序，移动、攻击和死亡帧共享同一方向映射。
8. 坦克没有攻击目标或强制攻击任务时，炮塔立即回正并跟随底盘方向。

## 图集约定

AI方向图集从左到右固定为：

```text
上 → 左上 → 左 → 左下 → 下 → 右下 → 右 → 右上
```

引擎的方向索引仍是：

```text
右 → 右下 → 下 → 左下 → 左 → 左上 → 上 → 右上
```

两者通过 `AI_ATLAS_COLUMN_BY_ENGINE_DIRECTION` 显式转换。
