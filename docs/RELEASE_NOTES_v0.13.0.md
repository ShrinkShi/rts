# Iron Meridian RTS v0.13.0

## RA2 / Yuri's Revenge 可交互资源浏览器

v0.13.0 不再把资源数据库当作静态文本页，而是把它重构为素材管线的可交互验收工具。该阶段的目标是先证明 SHP、VXL/HVA、建筑组合动画、所属色遮罩和声音事件能够在 Godot 中被统一浏览、播放和诊断，再进入 v0.14 的实际遭遇战纵切接入。

## 界面重构

- 删除旧版依赖固定 `position/size` 的排版。
- 使用 `MarginContainer`、`VBoxContainer`、`GridContainer`、`ScrollContainer` 和分栏容器构建自适应界面。
- 使用 `SystemFont`，依次尝试微软雅黑、Noto Sans CJK、思源黑体、苹方等中文字体，并允许系统回退。
- 详情字段改为真实 Label 节点逐行布局，不再将大量中文文本叠在同一绘制区域。
- 支持对象、声音、CSF 文本和官方地图四种浏览模式。
- 支持搜索、类别筛选和“只显示已生成预览”筛选。

## 动画预览

- 31 个步兵对象：按照 Art Sequence 解析 Ready、Guard、Walk、FireUp、Prone、Crawl、Die、Deploy 等动作。
- 78 个载具与 11 个飞行器：组合 VXL/HVA 车体、炮塔和炮管，提供八方向预览。
- 3 个 SHP 载具：按照 Facings、WalkFrames、FiringFrames 和 StandingFrames 切分。
- 56 个建筑对象：组合主体状态、Buildup、ActiveAnim、受损动画和生产动画；代表性建筑支持六种剧院切换。
- 共生成 176 个对象预览、1,077 个动画定义和 15,997 个帧引用。
- 支持动画选择、方向选择、剧院选择、所属色选择、播放/暂停、逐帧、循环和速度调整。
- 预览 PNG 使用运行时读取，避免让 Godot 为三万余张诊断帧生成导入缓存。
- 修正旧 VXL 点投影器的固定 2×2 绘制缺陷：体素绘制面积随画布拟合比例变化，减少载具表面的梳状透明缝隙。

## 所属色

- SHP/VXL 颜色索引 16～31 单独生成灰阶 remap mask。
- Godot 预览器将遮罩叠加为玩家颜色，不再根据“蓝色像素”猜测队伍色。
- 内置蓝、红、绿、黄、橙、紫、青、粉八种预览色。

## 声音试听

- 新增全局 `RA2AudioService`，使用 12 个 `AudioStreamPlayer` 组成并发播放池。
- 声音事件可选择具体样本或随机样本播放，并支持停止和音量调整。
- 单位页面会自动列出 Select、Move、Attack、Die、Deploy 等已解析声音角色。
- 声音页面可浏览 526 个事件及其实际样本。
- 1,825/1,825 个声音引用已解析；运行时使用源 PCM WAV 直接加载，音频目录通过 `.gdignore` 避免生成数千个 `.sample` 缓存。
- 播放失败只在状态栏显示明确原因，不再连续刷屏。

## 验证

- 42 个 GDScript 文件通过项目静态检查。
- 11,593 个源资源、559 个对象、5,212 条 CSF 文本和 526 个声音事件通过数据库验证。
- 176 个预览清单、1,077 个动画定义、15,997 个帧引用及所有帧路径通过专用验证。
- 1,716 个被声音事件引用的唯一 WAV 均存在并确认为 PCM WAV。
- 原有 13 个可视化 Prefab 和 8 个 SpriteFrames 资源通过回归检查。

## 当前边界

- 559 个对象都能查看 Rules/Art/武器/声音数据，但 v0.13.0 只为 176 个高价值且格式已验证的对象生成动画预览；剩余平民物件、Dummy 和少数特殊对象继续在后续补齐。
- VXL 渲染仍是离线软件等距预览器，已接入 VPL 色阶和 HVA 矩阵，但法线表、阴影和原引擎地形光照仍是近似实现。
- 本版是资源管线验收工具，不代表这些单位已经全部接入实际遭遇战。
- 下一阶段 v0.14 将以盟军、苏军、尤里三套基础生产链作为纵切，把验证过的真实图像、声音、科技树和武器数据接入游戏。
