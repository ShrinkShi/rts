# v0.8.3 发布说明

## 方向修复

坦克运行时图集仍按 `上、左上、左、左下、下、右下、右、右上` 排列。本版重新解释生图源中的上方对角帧：

- 坦克底盘左上使用原右上候选的水平镜像；
- 坦克底盘右上使用原始右上候选；
- 独立炮塔保留可靠的左上源帧，并用水平镜像生成右上，使其与底盘一致。

## 卡死与闪退风险处理

无法在没有用户崩溃日志的情况下证明唯一根因，但代码审查确认了几个会叠加形成卡死的确定性问题：

1. 每个移动单位每物理帧多次扫描全部单位，复杂度接近平方级；
2. `_follow_path()` 与 `_physics_process()` 重复执行单位穿透分离；
3. 每次受击都可能广播支援并扫描全部友军；
4. 密集交火可以无上限创建弹道与伤害数字节点；
5. Shift 命令及卡死绕行路径没有硬上限。

本版加入空间哈希邻域查询、去除重复分离、支援广播冷却、特效节点上限、命令和路径上限。高分辨率 AI 源图目录加入 `.gdignore`，避免 Godot 编辑器无意义导入源素材。

## 仍需提供的诊断材料

若 v0.8.3 仍然闪退，请提供 Godot 日志中崩溃前最后约 100 行。Windows 通常位于：

`%APPDATA%\Godot\app_userdata\Iron Meridian RTS\logs\godot.log`
