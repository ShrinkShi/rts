### v0.16.0-dev.7 Hotfix 1（2026-07-29）

- 修正 `draw_texture_rect_region()` 参数顺序，解决高度覆盖层无法解析的问题。
- 修复 `remap` 参数遮蔽全局函数的警告。
- 将不同视觉类型的三元构造改为显式分支。

### v0.16.0-dev.7 Hotfix 2（2026-07-29）

- 取消把整圈悬崖边缘格设为 AStar `solid` 的错误方案。
- 改用高度层之间的边连接限制：悬崖两侧可站立，但只能通过坡道跨层。
- 禁止从悬崖拐角斜穿。
- 单位被物理避让推出合法路径时回退本帧位移并重新寻路。

### v0.16.0-dev.8（2026-07-29）

**状态：开发分支，等待 Godot 4.7.1 实机验证**

- 从用户提供的 RA2/YR 资源包中读取 `ISOTEM.PAL`、`TIB*.TEM`、`TIBTRE01.TEM`、`WATER*.TEM` 和 `SHORE*.TEM`。
- 将原版温带资源转换为单一运行时图集，并以四段 Base64 文本随工程分发。
- 矿石实体改用原版 RA2 `TIB` 图像，并随储量切换稀疏程度。
- 新增原版矿柱动画；矿柱缓慢向附近合法地块扩散矿石。
- 新增原版温带水面与四方向岸线邻接覆盖层。
- 新增“温带海岸试验场”。
- 苏联 `NALASR` 哨戒炮删除手绘炮头，恢复 `nglasr.shp` 原版正常/受损合成画面。
- 苏联武装采矿车车体方向旋转 180°，炮塔继续独立瞄准。
- AI 进攻波和基地响应明确排除采矿车；武装采矿车保留自卫武器，但战略角色为经济单位。
- 电力显示统一为“当前用电量 / 总发电量”：75% 以下绿色，76%–100% 黄色，超过 100% 红色。
- 新增 GitHub Actions 静态验证工作流。

明确边界：

- 底层仍是 32×32 矩形逻辑网格，原版 60×30 菱形 TMP 只是适配显示。
- 水岸只完成四方向邻接，尚未覆盖全部原版复杂岸线组合。
- 原版树木、坡道与悬崖 TMP 尚未完成运行时替换。
- 必须通过 Godot 4.7.1 Parser、F5 对局和性能测试后才能归档为已验证版本。
