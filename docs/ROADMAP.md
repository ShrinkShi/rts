# 开发路线图（v0.8.3 后）

## P0：Godot 实机回归

- 使用 Godot 4.7 对全部脚本执行引擎级解析。
- 压测 10、50、100 辆载具交叉移动和同点集结。
- 验证建筑图集边缘裁剪和敌方炮塔攻击动画。
- 验证维修厂入口、出口、资金不足和建筑被摧毁时的车辆应急弹出。
- 检查战役菜单和建造栏在 1280×720、1600×900、1920×1080 下的布局。

## P1：群体导航

- 使用空间哈希替代遍历全部单位的邻居查询。
- 引入 ORCA/RVO 或简化速度障碍。
- 增加道路、建筑入口、精炼厂和维修厂预约队列。
- 为编队保存稳定槽位，避免单位在连续命令间交换位置。

## P2：维修和残骸

- 维修厂多车排队与等待区。
- 建筑维修/出售的专用音效和更完整动画。
- 车辆永久残骸、可清理残骸和道路阻挡。
- 维修优先级与自动维修策略。

## P3：地图系统

- 增加地图公平性自动测试：一矿、二矿、公共矿、可建造面积和窄口宽度。
- 地图预览显示矿区、树林和出生位。
- 增加程序化对称地图生成器与地图编辑器。
- 加入悬崖、高地、桥梁后重新设计寻路层。

## P4：战术系统

- 受击逃跑、集火、拉扯、保持射程和包抄。
- 支援半径、追击距离和交战规则的单独策略面板。
- 树林视野遮挡、伏击和火灾。
- 强制攻击的友伤规则与地面持续效果。

## P5：联网战斗

- 固定模拟 Tick 和稳定实体 ID。
- 主机权威或确定性锁步二选一。
- 命令广播、状态校验、快照恢复和掉线处理。
